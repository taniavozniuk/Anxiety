# Проєкт Next.js

Базова конфігурація для створення власного сайту.

## Запуск

```bash
npm run dev
```

Відкрийте http://localhost:3000.

## Основні файли

- `app/` — маршрути Next.js, спільні layouts та глобальні стилі. Файли маршрутів збирають сторінку з модулів.
- `features/` — функціональні модулі сайту. Кожен модуль зберігає власні компоненти, логіку, типи та дані.
- `components/ui/` — спільні базові UI-компоненти (зокрема компоненти shadcn).
- `components/layout/` — спільні частини макета, наприклад header і footer.
- `lib/` — утиліти та код, який використовується в різних модулях.
- `types/` — спільні типи, лише якщо їх використовують кілька модулів.
- `public/` — статичні файли.

### Додавання нової функції

Створюйте її в `features/<назва>/` і тримайте специфічний для неї код поруч. Наприклад:

```text
features/
  products/
    components/
    lib/
    types/
```

У `app/` залишайте тільки файли маршрутизації та компонування. Спільну логіку виносьте у `lib/`, а повторно використовувані UI-елементи — у `components/`. За замовчуванням компоненти є Server Components; додавайте `"use client"` лише там, де потрібна взаємодія в браузері.

Головний маршрут `app/page.tsx` використовує модуль `features/home/` як приклад цієї структури.
