# Проєкт Next.js

Базова конфігурація для створення власного сайту.

## Запуск

```bash
npm run dev
```

Відкрийте http://localhost:3000.

## Основні файли

- `app/page.tsx` — головна сторінка
- `app/layout.tsx` — спільний макет і метадані сайту
- `app/globals.css` — глобальні стилі
- `components/ui/button.tsx` — готовий компонент Button
